==========================================
PHASE 6: SUPABASE EDGE FUNCTIONS (FCM)
==========================================

Currently, the Android app generates an FCM token and stores it in the `fcm_tokens` table.
To actually send Push Notifications (e.g., when an order status changes to "READY" or "DELIVERED"), you need to set up a Supabase Edge Function that listens to database changes on the `orders` table.

### 1. Prerequisites
You need the Supabase CLI installed on your machine.
Run:
`npm install -g supabase`

### 2. Initialize Edge Functions
Inside the project root (`hakeem-cafeteria`):
`supabase init`

### 3. Create the Function
Create a function called `send-fcm`:
`supabase functions new send-fcm`

### 4. Write the Function
Edit `supabase/functions/send-fcm/index.ts` with the following Deno code:

```typescript
import { serve } from "https://deno.land/std@0.168.0/http/server.ts"
import { createClient } from "https://esm.sh/@supabase/supabase-js@2.7.1"
import { GoogleAuth } from "https://esm.sh/google-auth-library@8.7.0"

serve(async (req) => {
  try {
    const payload = await req.json()

    // We only care about order status updates
    if (payload.type !== 'UPDATE' || payload.table !== 'orders') {
      return new Response("Not an order update", { status: 200 })
    }

    const newOrder = payload.record
    const oldOrder = payload.old_record

    // Only notify if status changed
    if (newOrder.order_status === oldOrder.order_status) {
      return new Response("Status unchanged", { status: 200 })
    }

    // Get the FCM token for this user
    const supabaseClient = createClient(
      Deno.env.get('SUPABASE_URL') ?? '',
      Deno.env.get('SUPABASE_SERVICE_ROLE_KEY') ?? ''
    )

    const { data: fcmData } = await supabaseClient
      .from('fcm_tokens')
      .select('token')
      .eq('user_id', newOrder.user_id)
      .single()

    if (!fcmData?.token) {
      return new Response("No FCM token found", { status: 200 })
    }

    // Prepare FCM HTTP v1 API Request
    const auth = new GoogleAuth({
      credentials: JSON.parse(Deno.env.get('FIREBASE_SERVICE_ACCOUNT') ?? '{}'),
      scopes: ['https://www.googleapis.com/auth/firebase.messaging']
    })
    const client = await auth.getClient()
    const accessToken = await client.getAccessToken()

    const fcmPayload = {
      message: {
        token: fcmData.token,
        notification: {
          title: 'Order Status Updated',
          body: `Your order is now ${newOrder.order_status}`
        },
        data: {
          orderId: newOrder.id
        }
      }
    }

    const res = await fetch(`https://fcm.googleapis.com/v1/projects/YOUR_FIREBASE_PROJECT_ID/messages:send`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${accessToken.token}`
      },
      body: JSON.stringify(fcmPayload)
    })

    return new Response(JSON.stringify(await res.json()), { headers: { "Content-Type": "application/json" } })
  } catch (err) {
    return new Response(String(err?.message ?? err), { status: 500 })
  }
})
```

### 5. Deploy the Function
Set the environment variable containing your Firebase Service Account JSON:
`supabase secrets set FIREBASE_SERVICE_ACCOUNT='{ "type": "service_account", ... }'`

Deploy it:
`supabase functions deploy send-fcm`

### 6. Set up the Database Trigger
In the Supabase SQL Editor, run:
```sql
CREATE TRIGGER on_order_status_update
AFTER UPDATE ON orders
FOR EACH ROW
EXECUTE FUNCTION supabase_functions.http_request(
    'http://[YOUR_PROJECT_REF].functions.supabase.co/send-fcm',
    'POST',
    '{"Content-type":"application/json"}',
    '{}',
    '1000'
);
```
